# Nels.AI 前端开发指引 - 基础架构

## 1. 核心架构模式

### 1.1 通用模块结构
```
src/pages/{ModuleName}/
├── index.tsx                    # 主页面（列表/网格/树形）
├── detail.tsx                   # 详情页面
├── components/
│   ├── {entity}-card.tsx        # 卡片组件
│   ├── create-modal.tsx         # 创建/编辑模态框
│   ├── {entity}-table.tsx       # 表格组件
│   ├── {entity}-tree.tsx        # 树形组件
│   └── filter-bar.tsx           # 筛选栏组件
├── detail/
│   ├── header.tsx               # 详情页头部
│   ├── main-content.tsx         # 主内容区
│   └── sidebar.tsx              # 侧边栏
└── hooks/
    ├── use{Entity}List.ts       # 列表数据管理
    ├── use{Entity}Detail.ts     # 详情数据管理
    └── use{Entity}Filter.ts     # 筛选逻辑管理
```

### 1.2 技术栈
- **前端框架**: React + TypeScript
- **UI组件库**: Ant Design Pro + Ant Design
- **路由管理**: UmiJS
- **状态管理**: React Hooks + Context
- **样式方案**: Tailwind CSS + Less
- **国际化**: react-intl

## 3. 通用服务层模板

### 3.1 标准CRUD服务
```typescript:src/services/{module}.ts
import { request } from '@umijs/max';
import type { {Entity}, {Entity}Filter, PagedResult } from '@/types/{module}';

const API_PREFIX = '/api/{module}';

// 获取分页列表
export async function get{Entity}List(filter: {Entity}Filter): Promise<PagedResult<{Entity}>> {
  return request(`${API_PREFIX}/getList`, {
    method: 'POST',
    data: filter,
  });
}

// 获取单个实体
export async function get{Entity}(id: string): Promise<{Entity}> {
  return request(`${API_PREFIX}/get`, {
    method: 'POST',
    params: { id },
  });
}

// 创建实体
export async function create{Entity}(data: Partial<{Entity}>): Promise<{Entity}> {
  return request(`${API_PREFIX}/create`, {
    method: 'POST',
    data,
  });
}

// 更新实体
export async function update{Entity}(data: {Entity}): Promise<void> {
  return request(`${API_PREFIX}/update`, {
    method: 'POST',
    params: { id: data.id },
    data,
  });
}

// 删除实体
export async function delete{Entity}(id: string): Promise<void> {
  return request(`${API_PREFIX}/delete`, {
    method: 'POST',
    params: { id },
  });
}

// 批量删除
export async function delete{Entity}Batch(ids: string[]): Promise<void> {
  return request(`${API_PREFIX}/deleteBatch`, {
    method: 'POST',
    data: { ids },
  });
}

// 树形数据服务（如果需要）
export async function get{Entity}Tree(query?: TreeQuery): Promise<{Entity}Tree[]> {
  return request(`${API_PREFIX}/getTree`, {
    method: 'POST',
    data: query,
  });
}
```

### 3.2 错误处理规范
```typescript:src/utils/request.ts
import { message } from 'antd';

// 统一错误处理
export const handleApiError = (error: any) => {
  if (error.response) {
    const { status, data } = error.response;
    switch (status) {
      case 400:
        message.error(data.message || '请求参数错误');
        break;
      case 401:
        message.error('未授权，请重新登录');
        // 跳转到登录页
        break;
      case 403:
        message.error('权限不足');
        break;
      case 404:
        message.error('资源不存在');
        break;
      case 500:
        message.error('服务器内部错误');
        break;
      default:
        message.error('网络错误，请稍后重试');
    }
  } else {
    message.error('网络连接失败');
  }
};
```

## 5. 开发规范

### 5.1 命名规范
- **文件命名**: kebab-case (如: user-list.tsx)
- **组件命名**: PascalCase (如: UserList)
- **变量命名**: camelCase (如: userName)
- **常量命名**: UPPER_SNAKE_CASE (如: API_BASE_URL)
- **接口命名**: PascalCase + Interface后缀 (如: UserInterface)

### 5.2 目录结构规范
```
src/
├── components/          # 通用组件
├── pages/              # 页面组件
├── services/           # API服务
├── types/              # 类型定义
├── hooks/              # 自定义Hooks
├── utils/              # 工具函数
├── locales/            # 国际化文件
└── assets/             # 静态资源
```

### 5.3 代码质量要求
1. **TypeScript**: 严格类型检查，避免使用any
2. **ESLint**: 遵循项目ESLint规则
3. **Prettier**: 统一代码格式
4. **注释**: 关键逻辑必须添加注释
5. **测试**: 核心功能需要单元测试
