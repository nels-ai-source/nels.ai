# Nels.AI Frontend Development Guide - Card List Pattern

## 1. Applicable Scenarios

-   **Entity Management**: Display lists of any business entities
-   **Resource Management**: Display collections of resources
-   **Content Management**: Display content items with metadata
-   **Data Visualization**: Display structured data in card format

## 2. Pattern Features

-   **Card Display**: Present entity information in card format
-   **Search & Filter**: Support keyword search and conditional filtering
-   **CRUD Operations**: Support create, read, update, delete operations
-   **Responsive Layout**: Adapt to different screen sizes

## 3. Generic Hooks Template

### 3.1 List Data Management Hook

```typescript:src%2Fhooks%2Fuse%7BEntity%7DList.ts
import { useState, useCallback, useEffect } from 'react';
import { message } from 'antd';
import { useIntl } from '@umijs/max';
import { get{Entity}List, delete{Entity} } from '@/services/{module}';
import type { {Entity}, {Entity}Filter } from '@/types/{module}';

interface Use{Entity}ListOptions {
  defaultFilter?: Partial<{Entity}Filter>;
  autoLoad?: boolean;
}

export function use{Entity}List(options: Use{Entity}ListOptions = {}) {
  const { defaultFilter = {}, autoLoad = true } = options;
  const intl = useIntl();

  const [loading, setLoading] = useState(false);
  const [data, setData] = useState<{Entity}[]>([]);
  const [total, setTotal] = useState(0);
  const [filter, setFilter] = useState<{Entity}Filter>({
    skipCount: 0,
    maxResultCount: 20,
    ...defaultFilter,
  });

  // Load data
  const loadData = useCallback(async (newFilter?: Partial<{Entity}Filter>) => {
    const queryFilter = newFilter ? { ...filter, ...newFilter } : filter;

    try {
      setLoading(true);
      const result = await get{Entity}List(queryFilter);
      setData(result.items);
      setTotal(result.totalCount);
      if (newFilter) {
        setFilter(queryFilter);
      }
    } catch (error) {
      message.error(intl.formatMessage({ id: 'common.loadDataFailed' }));
      console.error(error);
    } finally {
      setLoading(false);
    }
  }, [filter, intl]);

  // Refresh data
  const refresh = useCallback(() => {
    loadData();
  }, [loadData]);

  // Search
  const search = useCallback((keyword: string) => {
    loadData({ keyword, skipCount: 0 });
  }, [loadData]);

  // Filter data
  const filterData = useCallback((newFilter: Partial<{Entity}Filter>) => {
    loadData({ ...newFilter, skipCount: 0 });
  }, [loadData]);

  // Pagination
  const paginate = useCallback((page: number, pageSize: number) => {
    loadData({
      skipCount: (page - 1) * pageSize,
      maxResultCount: pageSize,
    });
  }, [loadData]);

  // Delete item
  const deleteItem = useCallback(async (id: string) => {
    try {
      await delete{Entity}(id);
      message.success(intl.formatMessage({ id: 'common.deleteSuccess' }));
      refresh();
    } catch (error) {
      message.error(intl.formatMessage({ id: 'common.deleteFailed' }));
      console.error(error);
    }
  }, [refresh, intl]);

  useEffect(() => {
    if (autoLoad) {
      loadData();
    }
  }, []);

  return {
    loading,
    data,
    total,
    filter,
    loadData,
    refresh,
    search,
    filterData,
    paginate,
    deleteItem,
  };
}
```

## 4. Main Page Component Template

### 4.1 Card List Page

```typescript:src%2Fpages%2F%7BModule%7D%2Findex.tsx
import React, { useState } from 'react';
import { PageContainer } from '@ant-design/pro-components';
import { Button, Input, Pagination, Empty, Skeleton } from 'antd';
import { PlusOutlined } from '@ant-design/icons';
import { useIntl } from '@umijs/max';

import { use{Entity}List } from '@/hooks/use{Entity}List';
import { {Entity}Card } from './components/{entity}-card';
import { CreateModal } from './components/create-modal';
import { FilterBar } from './components/filter-bar';

const {Entity}List: React.FC = () => {
  const intl = useIntl();
  const {
    loading,
    data,
    total,
    filter,
    search,
    filterData,
    paginate,
    refresh,
  } = use{Entity}List();

  const [createModalOpen, setCreateModalOpen] = useState(false);

  return (
    <PageContainer>
      {/* Search and Filter Bar */}
      <div className="flex items-center justify-between mb-4">
        <div className="flex items-center gap-2">
          <FilterBar onFilter={filterData} />
          <Input.Search
            placeholder={intl.formatMessage({ id: 'common.searchPlaceholder' })}
            style={{ width: 200 }}
            allowClear
            onSearch={search}
          />
        </div>
        <Button
          icon={<PlusOutlined />}
          type="primary"
          onClick={() => setCreateModalOpen(true)}
        >
          {intl.formatMessage({ id: 'common.create' })}
        </Button>
      </div>

      {/* Content Area */}
      {loading ? (
        <Skeleton active />
      ) : data.length === 0 ? (
        <Empty description={intl.formatMessage({ id: 'common.noData' })} />
      ) : (
        <>
          <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-4 xl:grid-cols-5 gap-4">
            {data.map((item) => (
              <{Entity}Card
                key={item.id}
                data={item}
                onUpdate={refresh}
              />
            ))}
          </div>
          <Pagination
            current={Math.floor(filter.skipCount! / filter.maxResultCount!) + 1}
            pageSize={filter.maxResultCount}
            total={total}
            onChange={paginate}
            className="flex justify-end mt-4"
            showSizeChanger
            showQuickJumper
            showTotal={(total, range) =>
              intl.formatMessage(
                { id: 'common.paginationTotal' },
                { total, start: range[0], end: range[1] }
              )
            }
          />
        </>
      )}

      <CreateModal
        open={createModalOpen}
        onOpenChange={setCreateModalOpen}
        onSuccess={refresh}
      />
    </PageContainer>
  );
};

export default {Entity}List;
```

## 5. Card Component Template

### 5.1 Generic Card Component

```typescript:src%2Fpages%2F%7BModule%7D%2Fcomponents%2F%7Bentity%7D-card.tsx
import React, { useState } from 'react';
import { Card, Button, Dropdown, Modal, Tag, Avatar } from 'antd';
import { MoreOutlined, StarOutlined, EditOutlined, DeleteOutlined } from '@ant-design/icons';
import { history, useIntl } from '@umijs/max';

import { delete{Entity} } from '@/services/{module}';
import type { {Entity} } from '@/types/{module}';

interface {Entity}CardProps {
  data: {Entity};
  onUpdate: () => void;
  cardConfig?: {
    showAvatar?: boolean;
    showTags?: boolean;
    showActions?: boolean;
    avatarField?: string;
    titleField?: string;
    descriptionField?: string;
    tagField?: string;
    statusField?: string;
  };
}

export const {Entity}Card: React.FC<{Entity}CardProps> = ({
  data,
  onUpdate,
  cardConfig = {
    showAvatar: true,
    showTags: true,
    showActions: true,
    avatarField: 'avatar',
    titleField: 'title',
    descriptionField: 'description',
    tagField: 'category',
    statusField: 'status',
  }
}) => {
  const { Meta } = Card;
  const intl = useIntl();
  const [loading, setLoading] = useState(false);

  const handleDelete = async () => {
    try {
      setLoading(true);
      await delete{Entity}(data.id);
      onUpdate();
    } catch (error) {
      console.error('Failed to delete entity:', error);
    } finally {
      setLoading(false);
    }
  };

  const handleCardClick = () => {
    history.push(`/{module}/detail/${data.id}`);
  };

  const handleEdit = () => {
    history.push(`/{module}/edit/${data.id}`);
  };

  const dropdownItems = [
    {
      key: 'edit',
      label: intl.formatMessage({ id: 'common.edit' }),
      icon: <EditOutlined />,
      onClick: ({ domEvent }) => {
        domEvent?.stopPropagation();
        handleEdit();
      },
    },
    {
      key: 'duplicate',
      label: intl.formatMessage({ id: 'common.duplicate' }),
      onClick: ({ domEvent }) => {
        domEvent?.stopPropagation();
        // Implement duplicate logic
      },
    },
    {
      type: 'divider',
    },
    {
      key: 'delete',
      label: intl.formatMessage({ id: 'common.delete' }),
      icon: <DeleteOutlined />,
      danger: true,
      onClick: ({ domEvent }) => {
        domEvent?.stopPropagation();
        Modal.confirm({
          title: intl.formatMessage({ id: 'common.deleteConfirmTitle' }),
          content: intl.formatMessage({ id: 'common.deleteConfirmContent' }),
          onOk: handleDelete,
        });
      },
    },
  ];

  const getFieldValue = (field: string) => {
    return data[field as keyof typeof data];
  };

  return (
    <Card
      className="group cursor-pointer hover:shadow-md transition-shadow"
      onClick={handleCardClick}
      loading={loading}
      actions={cardConfig.showActions ? [
        <Button
          key="star"
          type="text"
          icon={<StarOutlined />}
          onClick={(e) => e.stopPropagation()}
          title={intl.formatMessage({ id: 'common.favorite' })}
        />,
        <Dropdown
          key="more"
          menu={{ items: dropdownItems }}
          trigger={['click']}
        >
          <Button
            type="text"
            icon={<MoreOutlined />}
            onClick={(e) => e.stopPropagation()}
            title={intl.formatMessage({ id: 'common.moreActions' })}
          />
        </Dropdown>,
      ] : undefined}
    >
      <Meta
        avatar={
          cardConfig.showAvatar ? (
            <Avatar
              src={getFieldValue(cardConfig.avatarField!) || '/default-avatar.png'}
              size={48}
              shape="square"
            />
          ) : undefined
        }
        title={
          <div className="flex items-center justify-between">
            <span className="truncate">{getFieldValue(cardConfig.titleField!)}</span>
            {cardConfig.showTags && (
              <Tag color="blue">{getFieldValue(cardConfig.tagField!)}</Tag>
            )}
          </div>
        }
        description={
          <div className="space-y-2">
            <div className="text-sm text-gray-600 line-clamp-2">
              {getFieldValue(cardConfig.descriptionField!)}
            </div>
            <div className="flex items-center justify-between text-xs text-gray-400">
              <span>
                {new Date(data.lastModificationTime || data.creationTime)
                  .toLocaleDateString()}
              </span>
              <span>{getFieldValue(cardConfig.statusField!)}</span>
            </div>
          </div>
        }
      />
    </Card>
  );
};
```

## 6. Filter Bar Component

### 6.1 Generic Filter Bar

```typescript:src%2Fpages%2F%7BModule%7D%2Fcomponents%2Ffilter-bar.tsx
import React, { useState } from 'react';
import { Select, DatePicker, Button, Space } from 'antd';
import { ReloadOutlined } from '@ant-design/icons';
import { useIntl } from '@umijs/max';

interface FilterOption {
  label: string;
  value: any;
}

interface FilterConfig {
  key: string;
  type: 'select' | 'dateRange' | 'multiSelect';
  placeholder?: string;
  options?: FilterOption[];
  width?: number;
  allowClear?: boolean;
  showSearch?: boolean;
}

interface FilterBarProps {
  onFilter: (filter: any) => void;
  filterConfigs?: FilterConfig[];
}

export const FilterBar: React.FC<FilterBarProps> = ({
  onFilter,
  filterConfigs = []
}) => {
  const intl = useIntl();
  const [filterValues, setFilterValues] = useState<any>({});

  const handleFilterChange = (key: string, value: any) => {
    const newValues = { ...filterValues, [key]: value };
    setFilterValues(newValues);
    onFilter(newValues);
  };

  const handleReset = () => {
    setFilterValues({});
    onFilter({});
  };

  const renderFilter = (config: FilterConfig) => {
    const commonProps = {
      placeholder: config.placeholder || intl.formatMessage({ id: `filter.${config.key}` }),
      style: { width: config.width || 120 },
      allowClear: config.allowClear !== false,
      value: filterValues[config.key],
      onChange: (value: any) => handleFilterChange(config.key, value),
    };

    switch (config.type) {
      case 'select':
        return (
          <Select
            {...commonProps}
            options={config.options}
            showSearch={config.showSearch}
            filterOption={config.showSearch ? (input, option) =>
              (option?.label ?? '').toLowerCase().includes(input.toLowerCase())
            : undefined}
          />
        );
      case 'multiSelect':
        return (
          <Select
            {...commonProps}
            mode="multiple"
            options={config.options}
            showSearch={config.showSearch}
            filterOption={config.showSearch ? (input, option) =>
              (option?.label ?? '').toLowerCase().includes(input.toLowerCase())
            : undefined}
          />
        );
      case 'dateRange':
        return (
          <DatePicker.RangePicker
            {...commonProps}
            placeholder={[
              intl.formatMessage({ id: 'common.startDate' }),
              intl.formatMessage({ id: 'common.endDate' })
            ]}
          />
        );
      default:
        return null;
    }
  };

  return (
    <Space wrap>
      {filterConfigs.map((config) => (
        <React.Fragment key={config.key}>
          {renderFilter(config)}
        </React.Fragment>
      ))}

      <Button
        icon={<ReloadOutlined />}
        onClick={handleReset}
        title={intl.formatMessage({ id: 'common.reset' })}
      />
    </Space>
  );
};
```

## 7. Create/Edit Modal

### 7.1 Generic Modal Form

```typescript:src%2Fpages%2F%7BModule%7D%2Fcomponents%2Fcreate-modal.tsx
import React, { useEffect, useState } from 'react';
import { Form, Input, Select, Upload, message } from 'antd';
import { ModalForm } from '@ant-design/pro-components';
import { PlusOutlined } from '@ant-design/icons';
import { useIntl } from '@umijs/max';

import { create{Entity}, update{Entity} } from '@/services/{module}';
import type { {Entity} } from '@/types/{module}';

interface FormField {
  name: string;
  label: string;
  type: 'input' | 'textarea' | 'select' | 'upload' | 'number' | 'password';
  required?: boolean;
  maxLength?: number;
  options?: Array<{ label: string; value: any }>;
  rules?: any[];
  placeholder?: string;
  rows?: number;
}

interface CreateModalProps {
  open: boolean;
  values?: Partial<{Entity}>;
  type?: 'create' | 'edit';
  onOpenChange: (visible: boolean) => void;
  onSuccess: () => void;
  formFields?: FormField[];
  width?: number;
}

export const CreateModal: React.FC<CreateModalProps> = ({
  open,
  type = 'create',
  values,
  onOpenChange,
  onSuccess,
  formFields = [],
  width = 600,
}) => {
  const intl = useIntl();
  const [form] = Form.useForm();
  const [loading, setLoading] = useState(false);

  useEffect(() => {
    if (open) {
      if (type === 'edit' && values) {
        form.setFieldsValue(values);
      } else {
        form.resetFields();
      }
    }
  }, [open, type, values, form]);

  const handleSubmit = async (formValues: any) => {
    try {
      setLoading(true);

      if (type === 'create') {
        await create{Entity}(formValues);
      } else {
        await update{Entity}({ ...values, ...formValues });
      }

      message.success(intl.formatMessage({ id: 'common.operationSuccess' }));
      onSuccess();
      onOpenChange(false);
    } catch (error) {
      message.error(intl.formatMessage({ id: 'common.operationFailed' }));
    } finally {
      setLoading(false);
    }
  };

  const renderFormField = (field: FormField) => {
    const commonProps = {
      placeholder: field.placeholder || intl.formatMessage({ id: `fields.${field.name}Placeholder` }),
    };

    const rules = field.rules || [];
    if (field.required) {
      rules.unshift({ required: true, message: intl.formatMessage({ id: 'validation.required' }) });
    }
    if (field.maxLength) {
      rules.push({ max: field.maxLength, message: intl.formatMessage({ id: 'validation.maxLength' }, { max: field.maxLength }) });
    }

    switch (field.type) {
      case 'input':
        return (
          <Input
            {...commonProps}
            maxLength={field.maxLength}
            showCount={!!field.maxLength}
          />
        );
      case 'textarea':
        return (
          <Input.TextArea
            {...commonProps}
            rows={field.rows || 4}
            maxLength={field.maxLength}
            showCount={!!field.maxLength}
          />
        );
      case 'select':
        return (
          <Select
            {...commonProps}
            options={field.options}
          />
        );
      case 'number':
        return (
          <Input
            {...commonProps}
            type="number"
          />
        );
      case 'password':
        return (
          <Input.Password
            {...commonProps}
          />
        );
      case 'upload':
        return (
          <Upload
            listType="picture-card"
            className="avatar-uploader"
            showUploadList={false}
            action="/api/upload"
            beforeUpload={(file) => {
              const isImage = file.type.startsWith('image/');
              if (!isImage) {
                message.error(intl.formatMessage({ id: 'validation.imageOnly' }));
              }
              const isLt2M = file.size / 1024 / 1024 < 2;
              if (!isLt2M) {
                message.error(intl.formatMessage({ id: 'validation.fileSizeLimit' }));
              }
              return isImage && isLt2M;
            }}
          >
            {values?.[field.name as keyof typeof values] ? (
              <img src={values[field.name as keyof typeof values] as string} alt="upload" style={{ width: '100%' }} />
            ) : (
              <div>
                <PlusOutlined />
                <div style={{ marginTop: 8 }}>
                  {intl.formatMessage({ id: 'common.upload' })}
                </div>
              </div>
            )}
          </Upload>
        );
      default:
        return <Input {...commonProps} />;
    }
  };

  return (
    <ModalForm
      form={form}
      title={intl.formatMessage({
        id: type === 'create' ? 'common.createTitle' : 'common.editTitle'
      })}
      open={open}
      onOpenChange={onOpenChange}
      onFinish={handleSubmit}
      loading={loading}
      width={width}
      modalProps={{
        destroyOnClose: true,
      }}
    >
      <Form.Item name="id" hidden />

      {formFields.map((field) => (
        <Form.Item
          key={field.name}
          name={field.name}
          label={field.label || intl.formatMessage({ id: `fields.${field.name}` })}
          rules={field.rules || []}
        >
          {renderFormField(field)}
        </Form.Item>
      ))}
    </ModalForm>
  );
};
```

## 10. Best Practices

### 10.1 Performance Optimization

1. **Virtual Scrolling**: Use react-window for large datasets
2. **Image Lazy Loading**: Implement Intersection Observer
3. **Debounced Search**: Use debounce for search input
4. **Caching Strategy**: Implement proper caching with React Query

### 10.2 User Experience

1. **Loading States**: Provide skeleton screens and loading animations
2. **Empty States**: Show friendly empty data messages
3. **Error Handling**: Implement graceful error handling and retry mechanisms
4. **Responsive Design**: Ensure compatibility across devices

### 10.3 Accessibility

1. **Keyboard Navigation**: Support Tab key navigation
2. **Screen Readers**: Provide appropriate aria labels
3. **Color Contrast**: Ensure sufficient color contrast
4. **Focus Management**: Implement proper focus order

### 10.4 Code Organization

1. **Component Composition**: Break down complex components into smaller, reusable pieces
2. **Type Safety**: Use TypeScript interfaces for all data structures
3. **Configuration-Driven**: Make components configurable through props
4. **Separation of Concerns**: Keep business logic separate from UI components

This card list pattern guide is applicable to all scenarios that require displaying data in card format with full internationalization support.
