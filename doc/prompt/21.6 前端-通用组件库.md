# Nels.AI 前端开发指引 - 通用组件库

## 1. 组件分类

### 1.1 基础组件
- **表单组件**: 输入框、选择器、上传组件等
- **展示组件**: 卡片、标签、徽章等
- **反馈组件**: 消息提示、确认框、加载状态等
- **导航组件**: 面包屑、分页、步骤条等

### 1.2 业务组件
- **筛选组件**: 高级筛选、快速筛选
- **操作组件**: 批量操作、快速操作
- **展示组件**: 数据卡片、状态展示
- **编辑组件**: 表单模态框、内联编辑

## 2. 筛选组件

### 2.1 高级筛选组件
```typescript:src/components/AdvancedFilter/index.tsx
import React, { useState, useImperativeHandle, forwardRef } from 'react';
import { Card, Form, Row, Col, Button, Input, Select, DatePicker, Space } from 'antd';
import { SearchOutlined, ReloadOutlined, DownOutlined, UpOutlined } from '@ant-design/icons';
import { useIntl } from '@umijs/max';

export interface FilterField {
  name: string;
  label: string;
  type: 'input' | 'select' | 'dateRange' | 'date' | 'number';
  options?: { label: string; value: any }[];
  placeholder?: string;
  rules?: any[];
  span?: number;
  hidden?: boolean;
}

interface AdvancedFilterProps {
  fields: FilterField[];
  onFilter: (values: any) => void;
  onReset: () => void;
  loading?: boolean;
  defaultCollapsed?: boolean;
  initialValues?: any;
}

export interface AdvancedFilterRef {
  getFieldsValue: () => any;
  setFieldsValue: (values: any) => void;
  resetFields: () => void;
}

const AdvancedFilter = forwardRef<AdvancedFilterRef, AdvancedFilterProps>(({
  fields,
  onFilter,
  onReset,
  loading = false,
  defaultCollapsed = true,
  initialValues = {},
}, ref) => {
  const [form] = Form.useForm();
  const intl = useIntl();
  const [collapsed, setCollapsed] = useState(defaultCollapsed);

  // 暴露方法给父组件
  useImperativeHandle(ref, () => ({
    getFieldsValue: () => form.getFieldsValue(),
    setFieldsValue: (values) => form.setFieldsValue(values),
    resetFields: () => form.resetFields(),
  }));

  // 处理搜索
  const handleSearch = () => {
    form.validateFields().then(values => {
      // 处理日期范围
      const processedValues = { ...values };
      Object.keys(processedValues).forEach(key => {
        const field = fields.find(f => f.name === key);
        if (field?.type === 'dateRange' && processedValues[key]) {
          processedValues[`${key}Start`] = processedValues[key][0];
          processedValues[`${key}End`] = processedValues[key][1];
          delete processedValues[key];
        }
      });
      onFilter(processedValues);
    });
  };

  // 处理重置
  const handleReset = () => {
    form.resetFields();
    onReset();
  };

  // 渲染表单项
  const renderFormItem = (field: FilterField) => {
    const commonProps = {
      placeholder: field.placeholder || intl.formatMessage({ id: `filter.${field.name}.placeholder` }),
      allowClear: true,
    };

    switch (field.type) {
      case 'input':
        return <Input {...commonProps} />;
      
      case 'select':
        return (
          <Select
            {...commonProps}
            options={field.options}
            showSearch
            filterOption={(input, option) =>
              (option?.label ?? '').toLowerCase().includes(input.toLowerCase())
            }
          />
        );
      
      case 'dateRange':
        return <DatePicker.RangePicker style={{ width: '100%' }} />;
      
      case 'date':
        return <DatePicker style={{ width: '100%' }} />;
      
      case 'number':
        return <Input type="number" {...commonProps} />;
      
      default:
        return <Input {...commonProps} />;
    }
  };

  // 分组字段：基础字段和高级字段
  const basicFields = fields.filter((_, index) => index < 3);
  const advancedFields = fields.filter((_, index) => index >= 3);

  return (
    <Card size="small" className="mb-4">
      <Form
        form={form}
        layout="vertical"
        initialValues={initialValues}
        onFinish={handleSearch}
      >
        {/* 基础筛选字段 */}
        <Row gutter={16}>
          {basicFields.map(field => (
            <Col key={field.name} span={field.span || 6}>
              <Form.Item
                name={field.name}
                label={field.label}
                rules={field.rules}
              >
                {renderFormItem(field)}
              </Form.Item>
            </Col>
          ))}
          
          {/* 操作按钮 */}
          <Col span={6}>
            <Form.Item label=" ">
              <Space>
                <Button
                  type="primary"
                  icon={<SearchOutlined />}
                  onClick={handleSearch}
                  loading={loading}
                >
                  {intl.formatMessage({ id: 'actions.search' })}
                </Button>
                <Button
                  icon={<ReloadOutlined />}
                  onClick={handleReset}
                >
                  {intl.formatMessage({ id: 'actions.reset' })}
                </Button>
                {advancedFields.length > 0 && (
                  <Button
                    type="link"
                    onClick={() => setCollapsed(!collapsed)}
                    icon={collapsed ? <DownOutlined /> : <UpOutlined />}
                  >
                    {collapsed ? '展开' : '收起'}
                  </Button>
                )}
              </Space>
            </Form.Item>
          </Col>
        </Row>
        
        {/* 高级筛选字段 */}
        {!collapsed && advancedFields.length > 0 && (
          <Row gutter={16}>
            {advancedFields.map(field => (
              <Col key={field.name} span={field.span || 6}>
                <Form.Item
                  name={field.name}
                  label={field.label}
                  rules={field.rules}
                >
                  {renderFormItem(field)}
                </Form.Item>
              </Col>
            ))}
          </Row>
        )}
      </Form>
    </Card>
  );
});

AdvancedFilter.displayName = 'AdvancedFilter';

export default AdvancedFilter;
```

### 3.1 批量操作组件
```typescript:src/components/BatchActions/index.tsx
import React from 'react';
import { Space, Button, Dropdown, Popconfirm, message } from 'antd';
import { DeleteOutlined, EditOutlined, DownOutlined, ExportOutlined } from '@ant-design/icons';
import { useIntl } from '@umijs/max';

export interface BatchAction {
  key: string;
  label: string;
  icon?: React.ReactNode;
  danger?: boolean;
  confirm?: {
    title: string;
    content?: string;
  };
  onClick: (selectedKeys: React.Key[], selectedRows: any[]) => void;
}

interface BatchActionsProps {
  selectedKeys: React.Key[];
  selectedRows: any[];
  actions: BatchAction[];
  onClearSelection: () => void;
}

const BatchActions: React.FC<BatchActionsProps> = ({
  selectedKeys,
  selectedRows,
  actions,
  onClearSelection,
}) => {
  const intl = useIntl();

  if (selectedKeys.length === 0) {
    return null;
  }

  // 主要操作（前3个）
  const primaryActions = actions.slice(0, 3);
  // 更多操作
  const moreActions = actions.slice(3);

  const handleAction = (action: BatchAction) => {
    if (action.confirm) {
      // 需要确认的操作
      return;
    }
    action.onClick(selectedKeys, selectedRows);
  };

  const renderAction = (action: BatchAction) => {
    const button = (
      <Button
        key={action.key}
        size="small"
        danger={action.danger}
        icon={action.icon}
        onClick={() => handleAction(action)}
      >
        {action.label} ({selectedKeys.length})
      </Button>
    );

    if (action.confirm) {
      return (
        <Popconfirm
          key={action.key}
          title={action.confirm.title}
          description={action.confirm.content}
          onConfirm={() => action.onClick(selectedKeys, selectedRows)}
          okText={intl.formatMessage({ id: 'actions.confirm' })}
          cancelText={intl.formatMessage({ id: 'actions.cancel' })}
        >
          {button}
        </Popconfirm>
      );
    }

    return button;
  };

  return (
    <div className="bg-blue-50 border border-blue-200 rounded p-3 mb-4">
      <div className="flex items-center justify-between">
        <div className="flex items-center space-x-4">
          <span className="text-sm text-gray-600">
            已选择 <strong>{selectedKeys.length}</strong> 项
            <Button
              type="link"
              size="small"
              onClick={onClearSelection}
              className="ml-2"
            >
              取消选择
            </Button>
          </span>
        </div>
        
        <Space>
          {primaryActions.map(renderAction)}
          
          {moreActions.length > 0 && (
            <Dropdown
              menu={{
                items: moreActions.map(action => ({
                  key: action.key,
                  label: action.label,
                  icon: action.icon,
                  danger: action.danger,
                  onClick: () => handleAction(action),
                })),
              }}
            >
              <Button size="small">
                更多操作 <DownOutlined />
              </Button>
            </Dropdown>
          )}
        </Space>
      </div>
    </div>
  );
};

export default BatchActions;
```

```typescript:src/components/QuickActions/index.tsx
import React from 'react';
import { Space, Button, Dropdown, Tooltip } from 'antd';
import { MoreOutlined } from '@ant-design/icons';

export interface QuickAction {
  key: string;
  label: string;
  icon?: React.ReactNode;
  type?: 'primary' | 'default' | 'dashed' | 'link' | 'text';
  danger?: boolean;
  disabled?: boolean;
  tooltip?: string;
  onClick: (record: any) => void;
}

interface QuickActionsProps {
  record: any;
  actions: QuickAction[];
  maxVisible?: number;
}

const QuickActions: React.FC<QuickActionsProps> = ({
  record,
  actions,
  maxVisible = 3,
}) => {
  // 可见操作
  const visibleActions = actions.slice(0, maxVisible);
  // 更多操作
  const moreActions = actions.slice(maxVisible);

  const renderAction = (action: QuickAction) => {
    const button = (
      <Button
        key={action.key}
        type={action.type || 'link'}
        size="small"
        danger={action.danger}
        disabled={action.disabled}
        icon={action.icon}
        onClick={() => action.onClick(record)}
      >
        {action.label}
      </Button>
    );

    if (action.tooltip) {
      return (
        <Tooltip key={action.key} title={action.tooltip}>
          {button}
        </Tooltip>
      );
    }

    return button;
  };

  return (
    <Space size="small">
      {visibleActions.map(renderAction)}
      
      {moreActions.length > 0 && (
        <Dropdown
          menu={{
            items: moreActions.map(action => ({
              key: action.key,
              label: action.label,
              icon: action.icon,
              danger: action.danger,
              disabled: action.disabled,
              onClick: () => action.onClick(record),
            })),
          }}
          trigger={['click']}
        >
          <Button type="link" size="small" icon={<MoreOutlined />} />
        </Dropdown>
      )}
    </Space>
  );
};

export default QuickActions;
```

```typescript:src/components/DataCard/index.tsx
import React from 'react';
import { Card, Avatar, Tag, Space, Button, Dropdown } from 'antd';
import { EditOutlined, DeleteOutlined, MoreOutlined } from '@ant-design/icons';

export interface DataCardAction {
  key: string;
  label: string;
  icon?: React.ReactNode;
  danger?: boolean;
  onClick: () => void;
}

interface DataCardProps {
  title: string;
  description?: string;
  avatar?: string | React.ReactNode;
  tags?: { label: string; color?: string }[];
  extra?: React.ReactNode;
  actions?: DataCardAction[];
  onClick?: () => void;
  className?: string;
  loading?: boolean;
}

const DataCard: React.FC<DataCardProps> = ({
  title,
  description,
  avatar,
  tags = [],
  extra,
  actions = [],
  onClick,
  className,
  loading = false,
}) => {
  const renderAvatar = () => {
    if (!avatar) return null;
    
    if (typeof avatar === 'string') {
      return <Avatar src={avatar} size={48} />;
    }
    
    return avatar;
  };

  const renderActions = () => {
    if (actions.length === 0) return [];

    const visibleActions = actions.slice(0, 2);
    const moreActions = actions.slice(2);

    const actionButtons = visibleActions.map(action => (
      <Button
        key={action.key}
        type="link"
        size="small"
        danger={action.danger}
        icon={action.icon}
        onClick={(e) => {
          e.stopPropagation();
          action.onClick();
        }}
      >
        {action.label}
      </Button>
    ));

    if (moreActions.length > 0) {
      actionButtons.push(
        <Dropdown
          key="more"
          menu={{
            items: moreActions.map(action => ({
              key: action.key,
              label: action.label,
              icon: action.icon,
              danger: action.danger,
              onClick: action.onClick,
            })),
          }}
          trigger={['click']}
        >
          <Button
            type="link"
            size="small"
            icon={<MoreOutlined />}
            onClick={(e) => e.stopPropagation()}
          />
        </Dropdown>
      );
    }

    return actionButtons;
  };

  return (
    <Card
      size="small"
      hoverable={!!onClick}
      loading={loading}
      className={className}
      onClick={onClick}
      actions={renderActions()}
    >
      <div className="flex items-start space-x-3">
        {renderAvatar()}
        
        <div className="flex-1 min-w-0">
          <div className="flex items-center justify-between mb-1">
            <h4 className="text-sm font-medium truncate" title={title}>
              {title}
            </h4>
            {extra}
          </div>
          
          {description && (
            <p className="text-xs text-gray-500 mb-2 line-clamp-2" title={description}>
              {description}
            </p>
          )}
          
          {tags.length > 0 && (
            <Space wrap size="small">
              {tags.map((tag, index) => (
                <Tag key={index} color={tag.color} size="small">
                  {tag.label}
                </Tag>
              ))}
            </Space>
          )}
        </div>
      </div>
    </Card>
  );
};

export default DataCard;
```

### 4.2 状态展示组件
```typescript:src/components/StatusDisplay/index.tsx
import React from 'react';
import { Tag, Badge, Tooltip } from 'antd';
import { 
  CheckCircleOutlined, 
  CloseCircleOutlined, 
  ExclamationCircleOutlined,
  ClockCircleOutlined,
  MinusCircleOutlined 
} from '@ant-design/icons';

export type StatusType = 'success' | 'error' | 'warning' | 'processing' | 'default';

export interface StatusConfig {
  text: string;
  type: StatusType;
  color?: string;
  icon?: React.ReactNode;
  tooltip?: string;
}

interface StatusDisplayProps {
  status: string | number;
  config: Record<string | number, StatusConfig>;
  mode?: 'tag' | 'badge' | 'text';
  showIcon?: boolean;
}

const StatusDisplay: React.FC<StatusDisplayProps> = ({
  status,
  config,
  mode = 'tag',
  showIcon = true,
}) => {
  const statusConfig = config[status];
  
  if (!statusConfig) {
    return <span>未知状态</span>;
  }

  const getIcon = (type: StatusType) => {
    if (!showIcon) return undefined;
    
    const iconMap = {
      success: <CheckCircleOutlined />,
      error: <CloseCircleOutlined />,
      warning: <ExclamationCircleOutlined />,
      processing: <ClockCircleOutlined />,
      default: <MinusCircleOutlined />,
    };
    
    return statusConfig.icon || iconMap[type];
  };

  const renderContent = () => {
    const icon = getIcon(statusConfig.type);
    
    switch (mode) {
      case 'badge':
        return (
          <Badge
            status={statusConfig.type}
            text={statusConfig.text}
          />
        );
      
      case 'text':
        return (
          <span className={`text-${statusConfig.type}`}>
            {icon && <span className="mr-1">{icon}</span>}
            {statusConfig.text}
          </span>
        );
      
      case 'tag':
      default:
        return (
          <Tag
            color={statusConfig.color}
            icon={icon}
          >
            {statusConfig.text}
          </Tag>
        );
    }
  };

  const content = renderContent();

  if (statusConfig.tooltip) {
    return (
      <Tooltip title={statusConfig.tooltip}>
        {content}
      </Tooltip>
    );
  }

  return content;
};

export default StatusDisplay;
```

```typescript:src/components/FormModal/index.tsx
import React, { useEffect, useState } from 'react';
import { Modal, Form, Spin, message } from 'antd';
import { useIntl } from '@umijs/max';

export interface FormField {
  name: string;
  label: string;
  component: React.ReactNode;
  rules?: any[];
  dependencies?: string[];
  hidden?: boolean;
  span?: number;
}

interface FormModalProps {
  open: boolean;
  title?: string;
  values?: any;
  fields: FormField[];
  onOpenChange: (open: boolean) => void;
  onSubmit: (values: any) => Promise<void>;
  width?: number;
  loading?: boolean;
  destroyOnClose?: boolean;
}

const FormModal: React.FC<FormModalProps> = ({
  open,
  title,
  values,
  fields,
  onOpenChange,
  onSubmit,
  width = 600,
  loading = false,
  destroyOnClose = true,
}) => {
  const [form] = Form.useForm();
  const intl = useIntl();
  const [submitting, setSubmitting] = useState(false);

  // 设置表单初始值
  useEffect(() => {
    if (open && values) {
      form.setFieldsValue(values);
    }
  }, [open, values, form]);

  // 提交表单
  const handleSubmit = async () => {
    try {
      const formValues = await form.validateFields();
      setSubmitting(true);
      await onSubmit(formValues);
      message.success('操作成功');
      onOpenChange(false);
      form.resetFields();
    } catch (error) {
      if (error.errorFields) {
        // 表单验证错误
        return;
      }
      message.error('操作失败');
      console.error(error);
    } finally {
      setSubmitting(false);
    }
  };

  // 取消操作
  const handleCancel = () => {
    onOpenChange(false);
    form.resetFields();
  };

  return (
    <Modal
      title={title || (values ? '编辑' : '新建')}
      open={open}
      onOk={handleSubmit}
      onCancel={handleCancel}
      width={width}
      confirmLoading={submitting}
      destroyOnClose={destroyOnClose}
      okText={intl.formatMessage({ id: 'actions.confirm' })}
      cancelText={intl.formatMessage({ id: 'actions.cancel' })}
    >
      <Spin spinning={loading}>
        <Form
          form={form}
          layout="vertical"
          preserve={false}
        >
          {fields.map(field => {
            if (field.hidden) return null;
            
            return (
              <Form.Item
                key={field.name}
                name={field.name}
                label={field.label}
                rules={field.rules}
                dependencies={field.dependencies}
              >
                {field.component}
              </Form.Item>
            );
          })}
        </Form>
      </Spin>
    </Modal>
  );
};

export default FormModal;
```

### 5.2 内联编辑组件
```typescript:src/components/InlineEdit/index.tsx
import React, { useState, useEffect } from 'react';
import { Input, Button, Space, message } from 'antd';
import { EditOutlined, CheckOutlined, CloseOutlined } from '@ant-design/icons';

interface InlineEditProps {
  value: string;
  onSave: (value: string) => Promise<void>;
  placeholder?: string;
  maxLength?: number;
  disabled?: boolean;
  type?: 'input' | 'textarea';
}

const InlineEdit: React.FC<InlineEditProps> = ({
  value,
  onSave,
  placeholder,
  maxLength,
  disabled = false,
  type = 'input',
}) => {
  const [editing, setEditing] = useState(false);
  const [inputValue, setInputValue] = useState(value);
  const [saving, setSaving] = useState(false);

  useEffect(() => {
    setInputValue(value);
  }, [value]);

  const handleEdit = () => {
    if (disabled) return;
    setEditing(true);
  };

  const handleSave = async () => {
    if (inputValue === value) {
      setEditing(false);
      return;
    }

    try {
      setSaving(true);
      await onSave(inputValue);
      setEditing(false);
      message.success('保存成功');
    } catch (error) {
      message.error('保存失败');
      console.error(error);
    } finally {
      setSaving(false);
    }
  };

  const handleCancel = () => {
    setInputValue(value);
    setEditing(false);
  };

  const handleKeyPress = (e: React.KeyboardEvent) => {
    if (e.key === 'Enter' && !e.shiftKey) {
      e.preventDefault();
      handleSave();
    } else if (e.key === 'Escape') {
      handleCancel();
    }
  };

  if (editing) {
    const InputComponent = type === 'textarea' ? Input.TextArea : Input;
    
    return (
      <div className="inline-edit-container">
        <InputComponent
          value={inputValue}
          onChange={(e) => setInputValue(e.target.value)}
          onKeyDown={handleKeyPress}
          placeholder={placeholder}
          maxLength={maxLength}
          autoFocus
          size="small"
          style={{ marginRight: 8 }}
        />
        <Space size="small">
          <Button
            type="primary"
            size="small"
            icon={<CheckOutlined />}
            loading={saving}
            onClick={handleSave}
          />
          <Button
            size="small"
            icon={<CloseOutlined />}
            onClick={handleCancel}
            disabled={saving}
          />
        </Space>
      </div>
    );
  }

  return (
    <div 
      className={`inline-edit-display ${disabled ? 'disabled' : 'cursor-pointer'}`}
      onClick={handleEdit}
    >
      <span className="inline-edit-text">
        {value || placeholder}
      </span>
      {!disabled && (
        <EditOutlined className="inline-edit-icon ml-2 opacity-0 group-hover:opacity-100" />
      )}
    </div>
  );
};

export default InlineEdit;
```

```typescript:src/pages/Example/index.tsx
import React, { useState, useRef } from 'react';
import { PageContainer } from '@ant-design/pro-components';
import { Button, Input, Select } from 'antd';

import AdvancedFilter, { FilterField, AdvancedFilterRef } from '@/components/AdvancedFilter';
import QuickFilter from '@/components/QuickFilter';
import BatchActions, { BatchAction } from '@/components/BatchActions';
import DataCard, { DataCardAction } from '@/components/DataCard';
import StatusDisplay from '@/components/StatusDisplay';

const ExamplePage: React.FC = () => {
  const filterRef = useRef<AdvancedFilterRef>(null);
  const [selectedKeys, setSelectedKeys] = useState<React.Key[]>([]);
  const [selectedRows, setSelectedRows] = useState<any[]>([]);

  // 筛选字段配置
  const filterFields: FilterField[] = [
    {
      name: 'name',
      label: '名称',
      type: 'input',
      placeholder: '请输入名称',
    },
    {
      name: 'type',
      label: '类型',
      type: 'select',
      options: [
        { label: '类型1', value: 'type1' },
        { label: '类型2', value: 'type2' },
      ],
    },
    {
      name: 'dateRange',
      label: '日期范围',
      type: 'dateRange',
    },
    {
      name: 'status',
      label: '状态',
      type: 'select',
      options: [
        { label: '启用', value: 1 },
        { label: '禁用', value: 0 },
      ],
    },
  ];

  // 快速筛选选项
  const quickFilterOptions = [
    { label: '全部', value: undefined },
    { label: '启用', value: 1, count: 10 },
    { label: '禁用', value: 0, count: 5 },
  ];

  // 批量操作配置
  const batchActions: BatchAction[] = [
    {
      key: 'delete',
      label: '删除',
      icon: <DeleteOutlined />,
      danger: true,
      confirm: {
        title: '确定要删除选中的项目吗？',
        content: '删除后无法恢复',
      },
      onClick: (keys, rows) => {
        console.log('批量删除', keys, rows);
      },
    },
  ];

  // 卡片操作配置
  const cardActions: DataCardAction[] = [
    {
      key: 'edit',
      label: '编辑',
      icon: <EditOutlined />,
      onClick: () => console.log('编辑'),
    },
    {
      key: 'delete',
      label: '删除',
      icon: <DeleteOutlined />,
      danger: true,
      onClick: () => console.log('删除'),
    },
  ];

  // 状态配置
  const statusConfig = {
    1: { text: '启用', type: 'success' as const },
    0: { text: '禁用', type: 'error' as const },
  };

  return (
    <PageContainer>
      {/* 高级筛选 */}
      <AdvancedFilter
        ref={filterRef}
        fields={filterFields}
        onFilter={(values) => console.log('筛选', values)}
        onReset={() => console.log('重置')}
      />

      {/* 快速筛选 */}
      <QuickFilter
        options={quickFilterOptions}
        onChange={(value) => console.log('快速筛选', value)}
        showCount
      />

      {/* 批量操作 */}
      <BatchActions
        selectedKeys={selectedKeys}
        selectedRows={selectedRows}
        actions={batchActions}
        onClearSelection={() => setSelectedKeys([])}
      />

      {/* 数据展示 */}
      <div className="grid grid-cols-1 md:grid-cols-2 lg:grid-cols-3 gap-4">
        {[1, 2, 3].map(id => (
          <DataCard
            key={id}
            title={`项目 ${id}`}
            description="这是一个示例项目的描述信息"
            tags={[
              { label: '标签1', color: 'blue' },
              { label: '标签2', color: 'green' },
            ]}
            extra={<StatusDisplay status={id % 2} config={statusConfig} />}
            actions={cardActions}
            onClick={() => console.log('点击卡片', id)}
          />
        ))}
      </div>
    </PageContainer>
  );
};

export default ExamplePage;
```

## 8. 最佳实践

### 8.1 组件设计原则
1. **单一职责**: 每个组件只负责一个功能
2. **可复用性**: 通过配置实现不同场景的复用
3. **可扩展性**: 预留扩展接口和插槽
4. **类型安全**: 使用TypeScript确保类型安全

### 8.2 性能优化
1. **懒加载**: 大型组件使用懒加载
2. **缓存**: 缓存计算结果和渲染结果
3. **虚拟化**: 大列表使用虚拟滚动
4. **防抖**: 搜索和筛选使用防抖

### 8.3 用户体验
1. **加载状态**: 提供友好的加载提示
2. **错误处理**: 优雅的错误处理和提示
3. **响应式**: 适配不同屏幕尺寸
4. **无障碍**: 支持键盘导航和屏幕阅读器

这个通用组件库指引提供了常用的业务组件，可以大大提高开发效率。
